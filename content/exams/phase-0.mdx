  - id: "view-vs-copy-sum"
    covers: "0.2"
    variants:
      - prompt: |-
          What number does this print?

              import numpy as np
              arr = np.arange(10)        # 0, 1, 2, ..., 9
              s = arr[2:5]
              s[:] = 100
              m = arr[arr > 50]
              m[:] = -1
              print(arr.sum())

          Enter just the number.
        answer: { type: "number", value: 336, tolerance: 0 }
        explanation: >-
          The slice arr[2:5] is a view, so writing 100 through it changes arr at
          positions 2, 3 and 4. The boolean mask arr[arr > 50] returns a copy, so
          writing -1 into m leaves arr untouched. arr is now 0, 1, 100, 100, 100,
          5, 6, 7, 8, 9: the original sum 45, minus 2 + 3 + 4 = 9, plus 300, which
          is 336.

## What this covers

This exam closes Phase 0. It has ten questions, two for each node:

- **0.1 Python fundamentals** - writing a loop and a function that produce one exact number.
- **0.2 Numpy and vectorized thinking** - predicting broadcast shapes and memory, and knowing a view from a copy.
- **0.3 Pandas** - cleaning a messy CSV to a figure you would defend, and predicting what a merge does to the row count.
- **0.4 Notebooks, environments, git** - what a reset does to history, and what hidden kernel state does to a notebook.
- **0.5 Plotting to see** - the defects in the sensor and Anscombe data that summary statistics hide.

Every answer is a number you compute and type in.

## How to prepare

The exam is open-tool and timed: use Python, a notebook, a calculator, the node datasets and your own session code. There is nothing to memorise. You need to be able to redo each session's work quickly on new numbers, and to follow a prompt's steps and rounding exactly. The questions change on a retake, so remembering answers will not help; re-running the session you stumbled on will.
