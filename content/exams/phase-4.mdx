          a = 2
          b = -3
          c = a * b
          d = c + a
          L = d * a

        answer: { type: "number", value: -8, tolerance: 0 }
        explanation: >-
          Forward: c = -6, d = -4, L = -8. Backward, summing one contribution
          per use of a. From L = d * a: a receives d = -4, and d.grad = a = 2.
          From d = c + a: a receives d.grad = 2, and c.grad = 2. From c = a * b:

          Check: L = a^2 * b + a^2, so dL/da = 2ab + 2a = -12 + 4 = -8.

          w = w - learning_rate * stored_gradient

        answer: { type: "number", value: 0.74, tolerance: 0.005 }

          have been 0.88.

## What this covers

One exam for the whole of phase 4. Every node has at least one question:

- **4.1 Build micrograd** - gradients through a small graph where a value is used more than once, and the local derivative of tanh
- **4.2 MLP from scratch** - parameter counts and the softmax cross-entropy loss
- **4.3 Training dynamics** - the loss an untrained network should start at, and what a forgotten zero_grad does to an update
- **4.4 CNNs** - the chain of output shapes and the parameter count of a small network
- **4.5 Sequences and attention** - scaled dot-product attention weights and a causal mask
- **4.6 Embeddings** - cosine similarity and nearest neighbours

## How to prepare

This is an open-tool exam. Use Python, a notebook or a calculator freely; nothing needs to be memorised, and there is nothing to recognise from a list. Every answer is a number you compute and type in. Read the rounding instruction in each prompt. If you do not pass, the questions use different numbers on a retake, so rework the session of any node you missed instead of remembering answers.
