## What this covers

Everything. The final draws two questions from each of the seven phase exams, so it runs from the tooling floor through to shipping a system:

- Phase 0: Tooling floor
- Phase 1: Math on demand
- Phase 2: Supervised learning
- Phase 3: Unsupervised and feature work
- Phase 4: Deep learning
- Phase 5: Applied LLM
- Phase 6: Ship it

## How to prepare

There is nothing new here. Every question tests a skill you have already been examined on, with numbers you have not seen. If a phase exam took you more than one attempt, that phase is the place to revise.

As with the phase exams, this is open-tool: use Python, a notebook or a calculator, exactly as you would at work. What you cannot do is take your time. Fourteen questions in seventy-five minutes is a little over five minutes each, which is enough to compute an answer and not enough to relearn a topic.

Passing opens the capstone. Passing the capstone as well earns the certificate.
