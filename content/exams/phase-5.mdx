## What this covers

One exam for the whole of phase 5. Every node has two questions:

- **5.1 Using LLM APIs properly** - cost against a classical model, and what temperature does to a next-token distribution
- **5.2 Vector search and retrieval** - recall at k from hand labels, and reciprocal rank fusion of dense and keyword rankings
- **5.3 RAG end to end** - sorting failures into retrieval, generation and corpus buckets, and measuring an abstention escape
- **5.4 Evaluating LLM systems** - Cohen's kappa for a judge, and which cases a change moved
- **5.5 Agents and tool use** - what a loop costs when history is resent, and how per-step reliability compounds

## How to prepare

This is an open-tool exam. Use Python, a notebook or a calculator freely; nothing needs to be memorised. Every number you need is in the prompt, with invented prices and token counts, and every answer is a number you compute and type in. Read each prompt for whether it wants a fraction between 0 and 1 and how many decimal places. If you do not pass, the questions use different numbers on a retake, so go back to the counting exercises in the nodes you missed.
